# CHAT_BOT

Chatbot com IA criado com Streamlit e OpenAI.

## Executar localmente

1. Instale as dependências:

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. Copie `.env.example` para `.env` e informe sua chave da OpenAI:

   ```env
   OPENAI_API_KEY=sua_chave_da_openai_aqui
   ```

3. Inicie o projeto:

   ```powershell
   python -m streamlit run main.py
   ```

4. Acesse <http://localhost:8501>.
